## Translation Dictionaries

- Bundled dictionaries support `en`, `ml`, and `ta`.
- They cover the canonical task actions, items, units, priorities, statuses, and the structured task/PaperBridge workflows.
- `formatStructuredTask` selects language-specific English, Malayalam, and Tamil sentence templates. User-entered locations and notes remain unchanged.

## Structured Task Model

`StructuredTaskInstruction` is optional and Zod-validated. It stores schema version, action code, optional item code, quantity, unit code, location text, and additional notes. It extends tasks without changing legacy free-text task records, IDs, timestamps, revisions, or authorship.

## Language Selection

`LanguageProvider` defaults to English, persists `relay-miden-language` locally, restores it after refresh, updates supported UI immediately, and never changes canonical task data.

## Task Creation Integration

The existing form retains free-text/custom mode and supports structured mode with localized action/item/unit controls, live instruction preview, local validation, and IndexedDB persistence. Structured task summaries and task details render through the selected language template.

## Task Display Integration

Structured tasks render dynamically on task rows, summaries, details, send selection, and receive preview. Legacy tasks display their original titles and free-text content unchanged.

## PaperBridge Compatibility

The existing `RELAY_MIDEN_PAPERBRIDGE` v1 envelope carries the optional structured instruction through the existing task payload. Canonical serialization, checksum, message identity, task identity, revisions, duplicate detection, import history, conflict handling, and legacy envelopes are preserved. No QR acknowledgment or synchronization protocol was added.

## Validation

The repository update path now removes `instruction: null` before validating the persisted task snapshot. This preserves the meaning of a user choosing free-text mode while allowing a formerly structured task to become a legacy/free-text task safely.
