## Prompt / Objective

Resolve the phone error: “Local storage is unavailable” when Relay Miden is opened through the same-Wi-Fi network link.

## Summary

Resolved a browser-context compatibility issue. Some mobile browsers permit IndexedDB over a local HTTP origin but do not expose `crypto.randomUUID()` there. Device identity initialization called that API after opening Dexie, which made the UI incorrectly report that local storage itself was unavailable. Relay Miden now generates UUID v4 values with `crypto.randomUUID()` when available and a cryptographically secure `crypto.getRandomValues()` fallback otherwise.
