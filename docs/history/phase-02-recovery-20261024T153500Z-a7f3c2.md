## Database and Schema Changes

- IndexedDB Database: `relay-miden-db` (Dexie v1 schema)
  - `tasks`: Primary key `id`. Indexes: `status`, `priority`, `action`, `createdAt`, `updatedAt`, `deletedAt`, compound `[status+updatedAt]`.
  - `operations`: Primary key `operationId`. Indexes: `taskId`, `operationType`, `timestamp`, `revision`, compound `[taskId+revision]`.
  - `settings`: Primary key `key`. Index: `updatedAt`.
- Schema definitions:
  - `TaskSchema`: UUID `id`, `action`, `title`, optional `description`, optional `quantity`, optional `unit`, `location`, `priority`, `status`, ISO `createdAt`, ISO `updatedAt`, `createdBy` (device ID), positive integer `revision`, nullable optional `deletedAt`.
  - `TaskOperationSchema`: UUID `operationId`, UUID `taskId`, `actorId`, `operationType` (`TASK_CREATE` | `TASK_UPDATE` | `TASK_DELETE`), ISO `timestamp`, integer `revision`, nullable integer `parentRevision`, full `payload` matching `TaskSchema`.
  - `CreateTaskInputSchema` & `UpdateTaskInputSchema`: Zod input validation schemas ensuring quantity requires unit, title length <= 120, description <= 1000, location <= 160.
