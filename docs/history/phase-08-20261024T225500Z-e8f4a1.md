## Service Worker Configuration
- Implemented with `vite-plugin-pwa` (Workbox `generateSW`).
- Precache manifest captures 32 assets (1,417 KiB total):
  - `index.html` entrypoint
  - Production JavaScript bundles (`index-[hash].js`, `workbox-window`, `virtual_pwa-register`)
  - Production CSS bundle (`index-[hash].css`)
  - Bundled DM Sans fonts (WOFF and WOFF2 formats for 400, 500, 600 weights)
  - All application icons and favicons
- Exclusions: API endpoints, Socket.IO endpoints, and health checks are denied from navigation fallback via `navigateFallbackDenylist: [/^\/socket\.io/, /^\/api/, /^\/health/]`.

## Cache Strategy
- **Static Assets**: Precached via Workbox with cryptographic hashes; cache entries are invalidated automatically when code changes.
- **Navigation Requests**: Workbox `NavigationRoute` returns `/index.html` to allow client-side React Router navigation while completely disconnected.
- **LAN API & WebSocket Traffic**: Strictly excluded from service worker caching. Handled by Socket.IO over live network only; never serves cached write responses.
- **User Task Data**: Strictly isolated in IndexedDB. Cache Storage never holds task entities, operations, or outbox queues.

## Offline Launch
1. User loads Relay Miden online or over LAN.
2. Service Worker installs and caches the 32 application shell resources.
3. User disconnects from Wi-Fi and mobile data.
4. User opens Relay Miden from home screen or browser.
5. The Service Worker returns the cached shell immediately without network requests.
6. React boots and connects to IndexedDB via Dexie.
7. Existing tasks, categories, and priority metrics render instantly.
8. User creates or updates tasks; mutations commit to IndexedDB and enqueue into the Phase 7 outbox.
9. PaperBridge QR generation works offline for optical handoffs.

## Install Experience

- **iOS (Safari)**: Detects iOS Safari and provides concise "Add to Home Screen" instructions (Share → Add to Home Screen).

## Update Management
- Configured in `registerType: 'prompt'` mode.
- When an updated Service Worker finishes installing, `onNeedRefresh` triggers `<UpdateNotification />`.
- Users review the notification and click "Update Now" at a convenient time, preventing surprise reloads during QR scans, task editing, or sync transactions.
- Clicking "Update Now" triggers `skipWaiting` and reloads the application.
- IndexedDB tasks, outbox entries, and conflict states remain 100% untouched.

## HTTPS LAN Configuration
- `scripts/generate-dev-cert.mjs`: Utility script that detects all local IPv4 network interfaces via `os.networkInterfaces()`, runs `mkcert` (or falls back to OpenSSL), and writes SAN certificates for `localhost`, `127.0.0.1`, and all LAN IPs into `certs/dev-key.pem` and `certs/dev-cert.pem`.
- `apps/web/vite.config.ts`: Loads dev certificates when `HTTPS=true` or `SSL_KEY_FILE` is passed, binding Vite to TLS.
- `apps/server/src/app.ts`: Creates a `node:https` server when TLS certificates are configured, enabling WSS for Socket.IO.
- Mixed-content prevention: Both frontend and server run over TLS simultaneously (`https://<IP>:5173` and `https://<IP>:3001`), eliminating browser mixed-content blocks.
- `npm run dev:https`: Starts both frontend and server in secure LAN mode.

## Known Limitations
1. Physical device installation and camera access on actual mobile phones require running `npm run dev:https` and trusting the generated certificate on the phone; simulated headless browsers verify API presence and secure context detection.
2. Background sync when all browser tabs are closed is not supported across all mobile browsers (especially iOS Safari); Relay Miden relies on the durable outbox to replay immediately upon app launch or reconnect.
3. Apple iOS Safari does not support the Chromium `beforeinstallprompt` event; iOS users follow the standard "Add to Home Screen" workflow documented in the app.
4. Single QR payload capacity remains capped at 2,048 bytes to ensure reliable scanning on mobile viewfinders.
